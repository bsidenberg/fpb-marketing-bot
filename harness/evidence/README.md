# Evidence — [PROJECT NAME]

No session is ACCEPTED without evidence here. "Code was written" is not evidence.

**Naming:** `S-XXX-[type]-[date].md` (or .txt/.png)

**Per session, capture as applicable:**
- test run output (full command + results)
- validation command output (lint, typecheck, build)
- independent review notes (reviewer role, findings, resolution)
- security review notes (when session touches auth/secrets/data/payments)
- integration verification results
- screenshots or recordings for UI acceptance criteria
- migration dry-run output (drafts only — production application requires Brian)

**Final project package (assembled at completion):**
- completed session ledger (SESSIONS.md, all ACCEPTED)
- requirements traceability (requirement → session → evidence)
- architecture-conformance report
- consolidated test results and security findings
- environment validation (ENVIRONMENT.md all VERIFIED)
- deployment readiness + rollback procedures
- operating documentation
- known limitations, unresolved risks, recurring costs
- final acceptance checklist for Brian

**Never include secret values in any evidence file.**
